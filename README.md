# ProjetoSpring5

Aplicativo web desenvolvido utilizando Streamlit para análise exploratória de anúncios de veículos.

## Funcionalidades

- Visualização da distribuição dos preços dos veículos;
- Gráfico de dispersão entre preço e quilometragem;
- Análises interativas utilizando Plotly Express.

## Tecnologias utilizadas

- Python
- Pandas
- Plotly Express
- Streamlit
